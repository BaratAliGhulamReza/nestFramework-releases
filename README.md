# Nest Framework Releases

Official production releases of Nest Framework for Autodesk Maya on Windows x64.

## Quick installation

1. Open the [Nest Framework 1.0.0 release](https://github.com/BaratAliGhulamReza/nestFramework-releases/releases/tag/v1.0.0).
2. Download `NestFramework_Professional_Installer.py`.
3. Drag and drop the Python file into the Maya viewport.
4. Choose **Install**, **Repair**, or **Uninstall** in the branded installer.

The installer detects the running Maya version, checks compatibility, downloads only the matching package, verifies its SHA-256 checksum, installs the `nestFramework` shelf and branded icon, and removes the temporary download.

## Supported versions

- Autodesk Maya 2025 — Windows x64
- Autodesk Maya 2026 — Windows x64

Unsupported Maya versions display a compatibility message and are not modified.
